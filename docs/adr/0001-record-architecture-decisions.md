# ADR 0001: Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-11-21

## Context
The project should stay maintainable over a long time. Reasons behind important
decisions get lost if they aren't written down.

## Decision
Significant decisions are recorded as short Architecture Decision Records in `docs/adr/`,
numbered sequentially, using the format: Status, Date, Context, Decision, Consequences.
Superseded ADRs are kept and marked as superseded.

## Consequences
A small writing overhead per decision, in exchange for a traceable design history.
