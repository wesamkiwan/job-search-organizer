# Job Search Organizer

A personal, local-first Django application to organize a job search: discover postings,
track applications and the exact documents sent, and analyze the process with a dynamic
dashboard.

> **Status:** specification phase. The code starts with [Phase 0](docs/06-roadmap.md).

## Privacy

All personal data (database, uploaded documents, `.env`) stays on your machine and is
excluded from version control.
